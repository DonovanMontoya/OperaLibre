# 0027. Publish read-along maps by successful scope

Status: Accepted.

## Context

One chapter can be difficult to align while the rest of the book has usable timing. A chapter retry needs to keep neighboring timing and grades intact.

## Decision

- Use the same scope plan for alignment and grading. Prefer a large single file's embedded chapters to bound error accumulation, while retaining whole-track handling when the chapter metadata cannot provide the structure. Treat omitted credits, reordered apparatus, and bonus audio as gaps. A matched illustration can remain covered without a text fragment.
- Allocate progress to alignment and the surrounding stages. Weight scopes by their duration when all durations are known. Use equal weights if any are missing. Report indeterminate work when the only scope supplies no intermediate progress.
- Re-run selected chapters only against a current map generated by OperaLibre. Preserve untouched timing precisely and carry over the neighboring grades. Keep an earlier chapter's usable fragments and clipped recovery gaps when the replacement fails. Create a gap when no prior timing exists. If no new chapter succeeds, leave the map in place and write the failure report. The map can remain usable when report generation fails, and a later backfill can grade it.
- Attempt each indicated repair once per chapter and cause, retaining an improvement only when it grades better. Clear abandoned recognition work before starting a repair and retain a pairing already fixed. A chapter swap needs a clear match to another chapter that exceeds its own text match. If no chapter explains the speech, test a confident language sample from beyond the introduction. A suggested language remains a suggestion until an administrator applies it.
- Stop repeated chapter attempts when the runtime fails from the start. Treat the aligner exiting without a result as failure even if the launcher reports a successful process exit. Preserve supplied error diagnoses and keep useful stderr for failures. Write maps compactly and match reports by their map identity.

## Consequences

A chapter retry can repair one part of the book while leaving successful timing intact. A report can explain why a scope still places no text.
